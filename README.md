# ACT AI Policy Enquiry Workflow

A Microsoft Copilot Studio portfolio project that turns a staff enquiry into a cited policy summary, an options brief or both. A verifier checks each draft against the research findings. A person makes the final editorial decision.

**Start with the [two-page Word brief](AI-Assurance-Triage-Options-Brief.docx).** It recommends how a branch could handle enquiries about recurring use of generative AI in workplace software. The [original agent report](AI-ASSURANCE-TRIAGE-REPORT.md) includes the verifier’s reasons for requesting revisions.
